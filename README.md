Jogo de Damas em Java (Swing)

Uma aplicação desktop interativa para dois jogadores que implementa o clássico jogo de tabuleiro de Damas. O projeto foca-se na manipulação de componentes gráficos com Java Swing e na validação de regras de jogo de tabuleiro.

Principais Funcionalidades:

Interface Gráfica (GUI): Tabuleiro 8x8 interativo construído com componentes Swing e suporte a estilização personalizada.

Mecânica de Jogo Completa: Suporte a movimentos diagonais, validação de regras por jogador e lógica de captura (saltar e comer peças do adversário).

Gestão de Pontuação: Controlo dinâmico de peças perdidas e atualização em tempo real do placar.

Janelas de Diálogo Inteligentes: Sistema de inputs para movimentos reposicionado para evitar a sobreposição ao tabuleiro de jogo.

Controlo de Turnos e Fim de Jogo: Alternância automática de turnos entre o Jogador 1 e o Jogador 2, com deteção de vitória.
